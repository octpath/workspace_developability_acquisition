# Gate1.2 Method Reference Addendum

**目的:** Gate1.2 freeze 文書自体は変更せず、feature family の method paper / software 参照を追記する。

**Registry:** [METHOD_REFERENCE_REGISTRY.csv](METHOD_REFERENCE_REGISTRY.csv)

## Usage

以降の family report / master summary では、method 名に加え **Paper** と **Repository** を clickable markdown link として表示する。

単一 canonical paper が無い family は `reference_type=REPRESENTATIVE_METHOD` とし、notes に `NO_SINGLE_CANONICAL_REFERENCE` を明示する。捏造 DOI/URL は禁止。
