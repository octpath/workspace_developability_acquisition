# Structure Gap Closure — エグゼクティブサマリ

FeNNix 本計算と並行（≤8 CPU）で、未検証だった構造ギャップ（連続表面疎水パッチ、Fab 空洞/パッキング、埋没未充足極性、ドメイン界面）を target-blind に凍結・抽出・評価した。

**結論:** 成熟した TmApp / HIC incumbent を **Primary かつ Shadow で改善する新 family は無し**。既存の露出芳香族（HIC）と配列/PLM（TmApp）が依然支配的。連続表面パッチは残基グラフの穴を埋めたが予測増分にはならず、Fab 内部欠陥系は OpenMM 調製依存が強く incumbent 非増分。GearNet は `DEFERRED_TECHNICAL`。

これで「汎用構造スカラーを足せば伸びる」系の残り穴は、増分基準では実質クローズしてよい。
