# Fv と Fab の構造比較詳細レポート

**対象読者:** 機械学習・情報科学の背景を持ち、抗体の専門知識は前提としない読者  
**データ:** Shehata コホート再構成 Fab（N=324）対既存 ESMFold Fv  
**方針:** target-blind（本レポートでは TmApp / HIC の値を見ていない）  
**関連成果物:** `comparisons/FV_VS_FAB_STRUCTURE_COMPARISON.csv`、`FAB_RECONSTRUCTION_REPORT_JA.md`

---

## 0. 一言でいうと

同じ抗体の可変部配列を、(A) 可変部だけ（**Fv**）として予測した構造と、(B) より大きい断片（**Fab**）の一部として予測した構造とで比較した。結果、**大半の抗体では可変部の骨格形状はほとんど変わらない**（結合 RMSD 中央値 ≈ 0.58 Å）。ただしこれは「定数領域が物理的に不要」を意味しない。実験の熱安定性指標（TmApp）は Fab で測られており、以降のエネルギー計算では Fab 全体を使う動機が残る。

---

## 1. なぜもともと Fv を使っていたのか

### 1.1 データの実体

配布データに主として含まれるのは、各抗体の可変領域アミノ酸配列である。

- **VH（variable heavy）**: 重鎖の可変ドメイン配列  
- **VL（variable light）**: 軽鎖の可変ドメイン配列  

抗体分子全体（IgG）には、この先に「定数領域」が続く。しかし公開テーブルには VH/VL が中心であり、定数部の正確な配列はサンプルごとに与えられていない。

### 1.2 配列 ML としての自然な選択

抗体間で大きく違うのは主に VH/VL（特に抗原結合ループ）である。定数領域はクラスが揃っていれば配列がほぼ共通で、**サンプル間の識別に効く配列バリエーションはほとんど増えない**。

これは、例えば画像認識で「全画素に共通の背景パターンを毎回入力に足しても、クラス間の識別には寄与しにくい」のに近い。共通定数配列を全サンプルに連結しても、多くの線形・カーネル・埋め込みモデルでは分散の増分が小さい。

機械学習の言葉では、次のように言える。

> Fv に絞ることは、「識別に効く変動がある部分表現」に計算を集中させることと近い。

配列ベースの埋め込み（PLM）、回帰、交差検証（CV）では、この選択は合理的である。計算コストも Fv の方が小さい。これまでの構造特徴パイプラインが Fv 予測を中心に据えてきた背景はここにある。
---

## 2. なぜ TmApp の「物理」では不足しうるのか

### 2.1 実験が測っている分子種

Shehata らの **TmApp** は、示差走査蛍光法（DSF）による **見かけの融解温度**である。重要なのは、測定対象が孤立した Fv ではなく、**Fab 断片**であることだ。

**Fab（fragment antigen-binding）** は、おおよそ次の二本鎖で構成される。

- 重鎖側: **VH + CH1**（＋切断後に残る短いヒンジ端の可能性）  
- 軽鎖側: **VL + CL**

ここで **CH1 / CL** は定数ドメイン（constant domain）である。配列はサンプル間でほぼ共通でも、**分子システムとしては新しい原子・界面・運動自由度が加わる**。

### 2.2 「定数入力」≠「定数効果」

配列空間では定数部が共通でも、非線形な構造・物理系では効果が定数とは限らない。

```
同じ CH1/CL
  + 異なる VH/VL
    → VH–CH1 / VL–CL / CH1–CL の相互作用が抗体ごとに変わりうる
    → 幾何・パッキング・配向・柔軟性・エネルギー地形が変わりうる
```

したがって、

- 「定数配列は ML 特徴として情報を増やさない」  
- 「定数ドメインは物理モデルに情報を足さない」  

は**同値ではない**。後者が本作業の動機である。

別の言い方をすると、定数ドメインは「全サンプルに共有されるバイアス項」ではなく、「可変部ごとに異なる相互作用相手」として働く可能性がある。ニューラルネットワークで言えば、共有のサブネットワークを付けても、上流の可変表現との積・非線形結合を通じて出力がサンプル依存になりうる、という状況に近い。

## 3. 何を再構成したか（何を「本物」と主張していないか）

### 3.1 分類

実験コンストラクトの監査結果、正確な実験 Fab 全長配列は復元できなかった。方針は次の通り。

**再構成クラス: `RECONSTRUCTED_EXPERIMENTAL_LIKE_FAB`**

- 組換え発現は **IgG1**（HIGH）  
- Fab は IgG を **papain**（2 h / 30°C）消化 → Protein A → CaptureSelect IgG-CH1 で精製（HIGH）  
- しかし **正確な allele・クローニング接合・papain 切断末端**は未確定  

したがってこれは **「試験管の中の正確な配列」の主張ではない**。実験種に近い、防御可能な再構成である。

### 3.2 使った定数配列（権威ソース）

| 役割 | ID | 出典 |
|------|-----|------|
| CH1（＋最小ヒンジ stub `EPKSC`） | `IGHG1_CH1_EPKSC_UNIPROT_P01857` | UniProt P01857 |
| Cκ | `IGKC_UNIPROT_P01834` | UniProt P01834 |
| Cλ（λ 全例で共通） | `IGLC2_UNIPROT_P0DOY2` | UniProt P0DOY2 |

軽鎖はプロジェクト注釈により **κ 238 / λ 86**。λ の定数遺伝子を抗体ごとに割り当てず、**事前宣言した IGLC2 一つ**を用いた（TmApp による選択はしていない）。

不確実性（明示）: 正確な IGHG1/IGKC/IGLC allele、ベクター接合、papain 後の重鎖 C 末端長。

## 4. Fv と Fab のアーキテクチャ（用語）

```
                 Fab（抗原結合断片）

            VH ──────── CH1
             │           │
            VL ──────── CL

            <── Fv ──>
```

| 用語 | 意味 |
|------|------|
| VH / VL | 可変ドメイン（配列の多様性の主座） |
| CH1 / CL | 定数ドメイン（クラスが揃えば配列ほぼ共通） |
| **Fv** | VH+VL だけ（可変部ペア） |
| **Fab** | Fv + CH1/CL（実験 TmApp に近い断片） |

本比較の問いを一文で書くと次である。

> **同じ VH/VL を、孤立 Fv として予測した場合と、Fab の一部として予測した場合で、可変部の幾何は変わるか？**

別抗体同士の比較ではない。

---

## 5. ESMFold で何をしたか

**ESMFold** は配列から立体構造を予測するモデルである。既存パイプラインと同じく、二本鎖は `鎖1:鎖2` 形式で入力した。

| 条件 | 入力 | 使う部分 |
|------|------|----------|
| A. 孤立 Fv | VH:VL | 予測全体 |
| B. 再構成 Fab | (VH+CH1):(VL+CL) | 予測から VH/VL 部分だけ抽出 |

その後、A と B の VH/VL を構造重ね合わせし、位置のずれ・配向・界面・表面などを測った。信頼度の参考として **pLDDT**（予測モデルの自信度プロキシ。実験精度そのものではない）も記録した。

ここで重要なのは、比較の単位が「抗体 ID ごと」であることだ。ある抗体の孤立 Fv 予測と、**同じ配列の** Fab 予測から切り出した可変部を比べている。モデルが違う抗体同士を混ぜて平均しているわけではない。したがって得られる分布は、「文脈（孤立 Fv か Fab か）を変えたときの、同一可変配列の予測差」の分布である。

---

## 6. 指標の直感的な意味

| 指標 | 直感 |
|------|------|
| **骨格 RMSD（Å）** | 重ね合わせ後の平均位置ずれ。小さいほど形が似る。おおよそ **&lt;1 Å** は「ほぼ同じ骨格」、**数 Å** は局所〜ドメイン配向の変化が疑わしい、という目安。 |
| **VH/VL 相対配向** | VH だけ重ねたあと VL の重心がどれだけ動くか。二ドメインの相対配置の変化。 |
| **CDR / HCDR3 RMSD** | 抗原結合ループの形の変化。**HCDR3** は通常いちばん可変なループ。 |
| **界面接触数** | VH–VL 近接残基数の変化（パッキングの粗い指標）。 |
| **露出芳香族 SASA** | Tyr/Trp/Phe の溶媒露出面積。表面疎水の代理。過去 HIC 文脈で芳香族露出が議論されたが、本レポートは構造記述が主で target-blind。 |
| **pLDDT** | モデル自信度。高いほど「モデルがはっきりしている」であり、実験構造との一致保証ではない。 |
| **H–L Cys 距離** | Fab で鎖間ジスルフィドを形成しうる Cys 同士の Sγ–Sγ 距離。**近い ≠ 共有結合が成立した**。ESMFold は結合を強制しない。 |

## 7. 全コホート結果（N=324）

### 7.1 Fv（孤立）対 Fab 文脈 VH/VL

| 指標 | 中央値 | IQR | q90 | 最大 | 平均 |
|------|--------|-----|-----|------|------|
| VH 骨格 RMSD (Å) | 0.59 | 0.38 | 1.29 | 3.55 | 0.73 |
| VL 骨格 RMSD (Å) | 0.27 | 0.17 | 0.57 | 1.23 | 0.33 |
| **結合 Fv RMSD (Å)** | **0.58** | **0.29** | **1.09** | **24.72** | 0.73 |
| 全 CDR RMSD (Å) | 0.76 | 0.81 | 2.00 | 28.30 | 1.04 |
| HCDR3 RMSD (Å) | 0.50 | 1.25 | 2.40 | 4.60 | 0.95 |
| 配向 COM 差 (Å) | 0.50 | 0.28 | 0.87 | 57.37 | 0.74 |
| VH–VL 接触数 Δ | 0 | 3 | 3 | 14 | −0.41 |
| 露出芳香族 SASA Δ (Å²) | −30.5 | 79.0 | 41.5 | 595.5 | −30.8 |

分布の形:

- 結合 Fv RMSD が **&lt;1 Å** の割合 ≈ **88%**、**&lt;2 Å** ≈ **98%**  
- → **一様に小さい寄与が主体で、少数の外れ値がある**分布（広くシフトしているわけではない）

### 7.2 観察（Observation）

ESMFold の予測上、**ほとんどの抗体で CH1/CL を付けても可変部骨格は大きく書き換えられない**。VL 側のずれは特に小さい。配向 COM も中央値 0.50 Å と小さい。界面接触の中央変化は 0。芳香族露出は中央値で約 −31 Å²（Fab 文脈で可変部芳香族がやや埋もれる方向）だが、ばらつきは大きい。

### 7.3 解釈（Interpretation）と非含意

これは **CASE A（類似）** に近い。

**言えること**

- 局所 VH/VL 幾何に主依存する解析では、既存 Fv 構造が第一近似として妥当な場合が多い。
- 「Fab を付けると可変部が系統的に別のフォールドに化ける」といった、強い文脈依存は少なくとも ESMFold 予測では見られない。

**言えないこと**

- 「だから Fab はエネルギー計算に不要」  
- CH1/CL は追加原子・界面・運動・エネルギー自由度を持ち、**静的 RMSD が小さくても物理量は変わりうる**。
- 「実験の Fab 結晶構造でも同じ」——これは予測同士の比較であり、実験構造との一致検証ではない。
- 「TmApp と無関係／有関係が証明された」——本解析は target-blind であり、安定性ラベルとの対応は見ていない。

平均だけでなく中央値・IQR・q90 を併記した理由は、少数の大きな外れ値が平均を引き上げるからである（結合 RMSD の平均 0.73 に対し中央値 0.58、最大 24.7）。結論は中央付近の塊で読むべきで、最大値だけで一般化すべきではない。

### 8.1 結合 Fv RMSD 上位

| ID | 結合 RMSD | VH | VL | HCDR3 | 配向 COM | global pLDDT |
|----|-----------|----|----|-------|----------|--------------|
| ADI-47265 | **24.72** | 3.55 | 0.52 | 3.99 | **57.37** | 82.5 |
| ADI-47221 | 2.75 | 3.00 | 0.24 | 3.55 | 3.89 | 83.8 |
| ADI-45469 | 2.35 | 3.12 | 0.69 | 4.52 | 1.11 | 85.2 |
| ADI-47223 | 2.33 | 3.02 | 0.28 | 4.60 | 2.37 | 85.9 |
| ADI-47125 | 2.26 | 2.84 | 0.31 | 4.28 | 2.64 | 87.6 |

### 8.2 記述的所見

- **ADI-47265** は配向も極端に崩れ、単一の構造失敗／マルチマー不整合として扱うべき **QC 外れ値**。生物学的一般則の証拠には使わない。  
- 2–3 Å 帯の数例は、**VH（特に HCDR3）側に変化が寄り、VL は比較的安定**。  
- 上位例の pLDDT は極端に低くはない（≈83–88）ため、「低自信だけが原因」とは言い切れない。ループ／鎖配向の予測差として記録する。

HCDR3 RMSD 上位も同系統（ADI-47223 / 45469 / 47125 など）で、変化はループ寄りに見える。

## 9. 全 Fab 構造 QC（予測そのものの健全性）

| 項目 | 結果 |
|------|------|
| 成功 | **324 / 324**（長さ一致） |
| global pLDDT | 中央値 **86.7**（P10–P90 84.7–88.3） |
| VH / VL / CH1 / CL pLDDT | 中央値 87.8 / 88.8 / 84.0 / 86.7 |
| severe clash | 中央値 **0**（最大 1） |
| CH1–CL 接触（8 Å） | 中央値 **39**（界面が「空中分解」していない） |

### H–L Cys 距離（Å）— 近接 ≠ 共有結合

| 集団 | 中央値 | q10 | q90 | max | &lt;2.6 Å | ≥3.0 Å |
|------|--------|-----|-----|-----|---------|--------|
| 全体 | 2.80 | 2.57 | 3.45 | 52.1 | 12.3% | 25.6% |
| κ | 2.74 | 2.55 | 2.95 | 52.1 | 16.0% | 6.3% |
| λ | 3.34 | 2.93 | 3.64 | 3.91 | 2.3% | **79.1%** |

κ と λ で期待トポロジーが異なりうるため、λ で距離が大きめなのは「失敗」と即断しない。いずれにせよ **ESMFold の近接は共有結合の証明ではない**。後続 FeNNix では、緩和後にこの幾何が化学的に妥当か検証し、**未解消のジスルフィド歪みがエネルギー特徴を支配しない**ようにする必要がある。

## 10. 中心メッセージ: ML と物理の区別

```
配列 ML の世界
  共通定数配列 → サンプル間の新しい識別情報はほぼ増えない
  → VH/VL 表現は効率的

非線形物理の世界
  同じ定数ドメイン + 異なる VH/VL
  → 相互作用・幾何・エネルギー・ダイナミクスは変わりうる
  → 「定数」でも効果は定数とは限らない
```

本比較が示したのは主に **Q1（幾何）** である。

| 問い | 本レポートの位置づけ |
|------|----------------------|
| **Q1** 定数文脈は Fv 幾何を変えるか？ | 大半では **ほとんど変えない**（観察） |
| **Q2** 幾何がほぼ同じでも、CH1/CL は TmApp 向けエネルギー／剛性情報を足すか？ | **未回答**（次の FeNNix 比較の仕事） |

## 11. TmApp とのつながり（仮説と限界）

**仮説（Hypothesis）:** 実験ターゲットは Fab の見かけの融解温度なので、分子種として Fab を使う物理計算は Fv よりアッセイに近い。

**しかし:**

- TmApp は静的な「形の安定性」そのものではない  
- DSF は温度上昇に伴う露出／構造転移の見かけの指標である  
- **静的 ESMFold 幾何だけでは TmApp は決まらない**

よって本再構成は、

- **後続物理計算のための、より妥当な分子基質**  

であり、

- **それ自体が TmApp 予測器**  

ではない。

---

## 12. 次の FeNNix 実験との接続

**FeNNix** は、構造を入力に局所的な力・エネルギー関連量を取り出す機械学習ポテンシャル系の枠組みである（本リポジトリでは FeNNix-v2 プロトコルが既にある）。同じ物理プロトコルで次を比較できる。

```
Fv  → FeNNix-v2 特徴
Fab → FeNNix-v2 特徴
```

- **Q1（本レポート）**: 定数文脈は Fv の予測幾何を変えるか → 大半ではほぼ変えない  
- **Q2（今後）**: 幾何がほぼ同じでも、CH1/CL を含む系のエネルギー／剛性特徴が TmApp 説明に寄与するか → 未回答  

もし Q2 で Fab 特徴が効けば、「幾何は似ているが物理量は違う」という、本レポートが警告した ML–物理のギャップが実証される。もし効かなければ、「少なくともこのポテンシャル特徴では定数領域の寄与は小さい」となる。どちらも科学的に有用であり、Q1 の結果だけでは決まらない。

両問を混ぜないことが重要である。
---

## 13. 限界

- 正確な実験定数 allele・papain 末端・接合は未確定（再構成は experimental-like）  
- ESMFold 自信度 ≠ 実験構造の正しさ  
- 鎖間ジスルフィドは明示拘束されていない  
- これら抗体の実験 Fab 結晶構造はない  
- 静的構造 ≠ 熱安定性  
- 芳香族 SASA 差は記述指標であり、本レポートでは target と相関させていない  

---

## 14. 結論（4問）

1. **再構成 full-Fab 構造生成は技術的に可能だったか？**  
   → **はい。324/324 成功。** CH1/CL 界面・全体 pLDDT も概ね妥当。

2. **Fab 文脈は Fv 幾何を実質的に変えるか？**  
   → **大半では No（結合 RMSD 中央値 0.58 Å）。** 少数外れ値あり（特に ADI-47265 は QC）。

3. **これまで孤立 Fv を使っていたのは構造的に合理的だったか？**  
   → **局所 VH/VL 幾何に依存する用途では、第一近似として合理的だった、という観察と整合する。**

4. **それでも後続の TmApp 向け物理で full Fab を使う正当化はあるか？**  
   → **ある。** 幾何が似ていても、定数領域はエネルギー・界面・運動の自由度を増やす。実験アッセイも Fab。次は FeNNix で Q2 を測る段階である。

## 付記: 主張の層

| 層 | 内容 |
|----|------|
| **観察** | ESMFold 上、孤立 Fv と Fab 文脈 VH/VL は大半で骨格が近い |
| **解釈** | 可変部の局所幾何だけなら Fv で足りることが多い可能性 |
| **仮説** | それでも Fab 物理は TmApp により近い情報を持ちうる |

予測構造の観察を、実験生物学の事実へすり替えてはいない。
