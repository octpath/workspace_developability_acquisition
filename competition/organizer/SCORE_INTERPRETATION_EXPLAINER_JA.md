# TmApp / HIC のスコアをどう読めばよいか
## 情報系メンバー向け解説

対象読者: ML / 情報科学 / データサイエンス / ソフトウェアエンジニア（抗体の専門知識は前提としない）  
数値の出典: `SCORE_INTERPRETATION_STATS.json`（最終ラベル N=324 と凍結 organizer CV）  
※ この文書は解説用です。コンペの採点ルールやデータは変更しません。

---

## まず結論（30秒版）

| Target | まず超える（local CV） | 強い目安 | 現benchmark超え | 非常に高精度 |
|---|---:|---:|---:|---:|
| TmApp | ~3.5 °C | ~2.8–3.0 °C | <2.5 °C | <2.0 °C |
| HIC | ~0.52 min | ~0.45–0.48 min | <0.40 min | <0.30 min |

**これはこのコンペ内での目安です。**  
「この値なら抗体開発に使える」という普遍的な産業基準ではありません。

強いスコアの科学的な読み方（短く）:

- **TmApp ~2.8–3.0 °C**: 配列から熱安定性に関する意味のある signal を捉えている。ただし related DSF の technical variation より誤差はまだ大きい。  
- **HIC ~0.45–0.48 min**: 配列から assay-specific な疎水性挙動を捉えている。ただし近縁 HIC protocol の reference-control variation（おおよそ ±0.12 min スケール）より誤差はまだ数倍大きい。

---

## 「3 °C の誤差」とは何か？

主評価指標は **MAE（Mean Absolute Error）** です。

TmApp で MAE = 3 °C とは、ざっくり言うと:

> 評価に使った抗体について、  
> 「予測値 − 実験値」の絶対値の平均が約 3 °C

という意味です。

単位が違うので、HIC の MAE = 0.5 min も同じ定義です（分単位の平均絶対誤差）。

重要な注意:

- MAE は **平均** の誤差です。  
- 「MAE = 2 °C だから、2 °C 違う抗体ペアは全部見分けられる」**ではありません**。  
- 同様に「MAE = 0.3 min だから、0.3 min 差は全部正しく順位付けできる」**でもありません**。

## なぜ「良いスコア」の話が紛らわしいのか

情報系の人が最初に混乱しやすいのは、次の3つが別物だという点です。

### ものさし1: 何も学習しない予測より良いか？

定数予測（例: 学習データの中央値を全部に出す）でも、ある程度の MAE は出ます。

このコンペの **local CV** ではおよそ:

| Target | 定数（median）baseline | organizer 強めモデル |
|---|---:|---:|
| TmApp | ≈ 3.54 °C | ≈ 2.78–2.95 °C |
| HIC | ≈ 0.52 min | ≈ 0.45–0.48 min |

ここから測る改善率を skill と呼ぶことがあります:

\[
\text{MAE skill} = 1 - \frac{\mathrm{MAE}_{model}}{\mathrm{MAE}_{baseline}}
\]

凍結値だとおおよそ:

- TmApp: 3.543 → 2.778 で **約 21.6%** 改善  
- HIC: 0.518 → 0.467 で **約 10.0%** 改善  

これは「コンペ内で、どれだけ baseline より賢いか」の指標です。  
臨床成功率や製造成功確率ではありません。

### ものさし2: 抗体間のばらつきに比べて誤差は大きいか？

最終データ（N=324）のラベル分布（実測）:

| | TmApp (°C) | HIC (min) |
|---|---:|---:|
| SD | ≈ 4.69 | ≈ 0.83 |
| IQR | ≈ 6.0 | ≈ 0.70 |
| MAD | ≈ 3.0 | ≈ 0.27 |
| P10–P90 | 64.5–75.5 | 8.75–10.40 |

直感:

- TmApp は抗体ごとにかなり広がっている（数十 °C レンジ）。  
- HIC は本体が狭いが、**右に長い尾（high tail）** があり、そこがスクリーニング上重要。

MAE ≈ 3 °C は「全部ランダム」ではないが、抗体間の差のスケールに対してはまだ大きい、という位置づけです。  
MAE / SD などの正規化は **記述用** であり、普遍的な合格点ではありません。

### ものさし3: 実験そのものの再現性にどこまで近いか？

ここが一番誤解されやすいです。

実験の再現性（同じ条件でもう一度測ったらどれだけ一致するか）と、  
ML の MAE（別の抗体の性質を配列から当てる誤差）は、**同じ数字でも意味が違います**。

文献から言える範囲（Shehata 自身の反復統計はパッケージ証拠では直接得られていない）:

- 関連する抗体 / 治療用タンパクの DSF では、technical variation が **サブ °C〜おおよそ 1 °C** 程度と報告されることがある。  
- 近縁の Adimab 系 HIC では、reference IgG を 127 回測って **8.6 ± 0.12 min** という報告がある（Jain et al. 2017）。

したがって:

> organizer の強いスコア（TmApp ~3 °C、HIC ~0.47 min）は  
> **学習としては強い**が、  
> **実験の置き換え精度としてはまだ遠い**

という読み方が安全です。

## コンペ相対と科学的解釈を分けて読む

### A. コンペ相対（はっきり言える）

- ~3.5 °C / ~0.52 min: baseline 級  
- ~2.8–3.0 °C / ~0.45–0.48 min: **強い**（現行 organizer benchmark）  
- <2.5 °C / <0.40 min: 現行 benchmark を明確に超える  
- <2.0 °C / <0.30 min: このデータセットでは非常に高精度

### B. 科学的解釈（慎重にしか言えない）

強いスコアが意味すること:

- 配列に、実験で測った性質と相関する情報がある。  
- 早期の候補優先順位付けの補助にはなりうる。

強いスコアが意味 **しない** こと:

- その抗体が developable である  
- 製造できる / 臨床で使える  
- DSF や HIC を置き換えられる  
- 「ノイズフロアに到達した」

## Public リーダーボードと local CV を混ぜない

参加者向けの目安は **local CV** が主です（自分で再現できるから）。

Public は N=81 と小さく、順位が揺れます。  
また TmApp では local CV ~2.8–3.0 が Public では mid-3s 付近に見えることがあります。

ルール:

- local CV の帯 → local CV と比較  
- リーダーボード → リーダーボード上の baseline / 他提出と比較  

「同じ数字だから同じ意味」ではありません。

---

## MAE と順位相関

- **MAE**: 値そのものの当てやすさ（本コンペの主指標）  
- **Spearman**: 並び順の一致（診断用）

主指標は MAE のままです。変更提案ではありません。  
スクリーニング用途の内部議論では、high-tail の拾い方や pairwise ranking も診断として有用です。

## よくある質問（MLエンジニア向け）

**Q. MAE が分かる。でも 3 °C と 1 °C で何が違うの？**  
A. 3 °C は「baseline よりかなり良い／悪い」の世界。1 °C は「関連 DSF の再現性スケールに近づく」世界。どちらも自動的に実験置換にはなりません。

**Q. HIC 0.47 は弱いのでは？**  
A. baseline 0.52 より明確に良く、organizer の強い帯です。弱いのは「実験再現性 ±0.12 と比べたとき」です。ものさしを混同しないでください。

**Q. では何を目指せばいい？**  
A. まず local CV で baseline（~3.5 / ~0.52）を安定して下回る。次に ~3.0 / ~0.47 帯。それを超えたら <2.5 / <0.40 が次の山。
