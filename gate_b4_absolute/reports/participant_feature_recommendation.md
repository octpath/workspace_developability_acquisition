# Participant feature recommendation

## Distribute (basic educational)
- VH/VL inferred germline family
- light-chain type (κ/λ)
- CDR lengths
- germline identity/distance
- basic IMGT region annotations

## Do NOT distribute
- donor
- B-cell subset
- organizer-only metadata

## Engineered predictive encodings
Position-by-position germline substitution matrices / complex mutation encodings: participants may construct; not required in the starter pack.
