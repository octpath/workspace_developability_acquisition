# Organizer role (B7)

During the live phase the organizer:
1. Accepts submission prediction files under `submissions/`
2. Returns ONLY Public MAE (+ personal Public rank / Δ vs previous)
3. Vaults Private MAE silently until after `participant/final_submission_choice_*.json` freeze
4. Reveals Private for all submissions for post-hoc analysis

Private labels and role membership were not exposed to participant decision logic.
