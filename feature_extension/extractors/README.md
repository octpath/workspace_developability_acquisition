# extractors/

Lightweight, participant-facing PDB feature extractors.

## Modules

| Module | What it computes | Equivalent to precomputed? |
|---|---|---|
| `extract_sasa.py` | Bio.PDB Shrake–Rupley total / class SASA, RASA summaries | Partial overlap with SASA-based families; not a dump of precomputed tables |
| `extract_aromatic.py` | AROMATIC-TOPO-style aromatic exposure (RASA thresholds 0.20 / 0.50) | Close in definition to `aromatic_topology.parquet` when CDR map supplied; not guaranteed bit-identical |
| `extract_surface_patch.py` | **Residue-graph** hydrophobic exposure (CA adjacency ≤ 8 Å among exposed hydrophobic residues) | **NOT** `continuous_surface.parquet` |
| `extract_interface.py` | Simple heavy–light contact count / BSA **proxy** | Not classical shape complementarity; Fab domain interfaces are in precomputed `fab_interface.parquet` |

## continuous_surface vs extract_surface_patch (read this)

**`data/precomputed_features/continuous_surface.parquet`** was generated by the organizer
Gap Closure Task B pipeline (`extract_surface_hic.py` / `STRUCTURE_GAP_CLOSURE_SPEC.md`):

- FreeSASA **Lee–Richards** atom SASA (probe 1.4 Å)
- Exterior **SAS sample points** (Fibonacci directions on atoms with SASA ≥ 0.5 Å²)
- Hydrophobic masks on KD / FP / BM scales
- Patches = connected components of hydrophobic **surface sample points** (link 2.0 Å)
- Patch **area / perimeter / compactness** from sample-point weights

This is a continuous **SAS-sampled molecular-surface** representation.
It is **not** a classical MSMS triangulated SES mesh, but it is also **not** a residue-CA graph.

**`extract_surface_patch.py`** is a lightweight helper that:

- computes residue SASA with Bio.PDB Shrake–Rupley
- selects exposed hydrophobic residues
- connects them by **CA–CA distance ≤ 8 Å**

These two products are **not numerically equivalent**. The extractor does **not** reproduce
the precomputed `continuous_surface` block.

## API

```python
from feature_extension.extractors import extract_sasa, extract_aromatic, extract_surface_patch

extract_sasa(pdb_path="...")
extract_aromatic(pdb_path="...", cdr_residue_keys=None)  # CDR fields NaN if map omitted
extract_surface_patch(pdb_path="...")  # residue-graph only
```

Failures raise exceptions; extractors never return sentinel `-999`.
